Ruzora provides a vetted marketplace of senior LATAM engineers, offering companies a rapid shortlist of qualified candidates within 72 hours. The platform combines AI-driven vetting with human expert reviews, ensuring engineers have passed coding challenges without AI assistance, live technical interviews, and integrity checks. Clients can book calls, access salary guides, and use tools like Sol, an AI hiring assistant, to streamline recruitment. Ruzora emphasizes transparency, fast turnaround, and high-quality talent for software development projects.

**Areas:** Hiring · LATAM · Engineering · Marketplace · AI · Talent

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Ruzora: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
